엔트리 바이브코딩 시작하기

AI 코딩 도우미(무료 ChatGPT로 쓸 수 있는 Codex, Claude Code 등)에게 저장소 링크와 아래 프롬프트를 주면, 엔트리 작품 파일(.ent)을 만들고 직접 실행해서 움직이는지까지 확인합니다.

저장소: github.com/205sla/entry-vibe-coding

준비물

  • 컴퓨터 — Windows, macOS, Linux 모두 됩니다.
  • Node.js — 22 버전 권장(최소 18.18).
  • git — 저장소를 받을 때 씁니다.
  • 인터넷 — 처음 설치할 때 엔트리 엔진 등을 내려받습니다(수 분).
  • AI 코딩 도우미 — 명령을 직접 실행할 수 있는 것(Codex, Claude Code 등).

1 환경 준비

빈 폴더를 AI 코딩 도우미의 작업 폴더로 열고 아래 프롬프트를 붙여 넣으세요. 설치와 확인 검사까지 알아서 진행하고, 무엇이 통과했는지 보고합니다.

환경 준비 — 빈 폴더에서 링크만 줄 때 
https://github.com/205sla/entry-vibe-coding 저장소로 엔트리 작품을 만들 수 있게 이 PC에 환경을 준비해줘.

1. 저장소를 이 폴더에 클론하고, 클론한 폴더의 AGENTS.md를 먼저 읽어. 거기서 안내하는 CLAUDE.md의
   "환경 준비"를 그대로 따라 해.
2. 순서는 npm install → npm run setup → npx playwright install chromium 이야.
   Chromium은 꼭 npm install 뒤에 설치해.
   Windows PowerShell에서 npm·npx가 "스크립트를 실행할 수 없으므로"로 막히면 npm.cmd·npx.cmd로 실행해.
3. 엔트리 엔진(entryjs)은 절대 빌드하지 마. setup이 이미 빌드된 파일을 받아 온다.
   setup이 실패하면 오류 메시지대로 조치한 뒤 다시 실행해.
4. 설치가 끝나면 아래로 확인해:
   - npm run test:smoke
   - npm run test:e2e   (편집기가 실제로 뜨는지)
   - node tools/play-check.mjs tests/fixtures/bounce-ball.ent   (예제 게임이 실제로 움직이는지)
5. 한국어로 보고해줘: 통과한 단계, 실패했거나 못 한 단계와 그 이유, 편집기 여는 방법
   (npm start → http://localhost:3000). 게임은 아직 만들지 마.
저장소를 이미 받아서 그 폴더를 열었다면 (짧은 판)

2 게임 만들기

환경 준비가 끝난 같은 대화에서 만들고 싶은 게임을 말하세요. 아래는 예시입니다. 조작 방법, 점수, 끝나는 조건을 적어 주면 결과가 훨씬 좋아집니다.

게임 요청 — 예시: 사과 받기 
사과 받기 게임 만들어줘. 방향키로 바구니를 좌우로 움직이고, 떨어지는 사과를 받으면 점수 +1, 3개 놓치면 게임 끝.
CLAUDE.md의 제작 사이클과 검증 사다리를 따르고, play-check 보고가 내 요청과 맞는지 비교해서 알려줘.

만든 작품은 games/<이름>/<이름>_001.ent처럼 번호가 붙어 저장되고, 고칠 때마다 _002, _003으로 새 파일이 생깁니다. 직접 보려면 npm start를 실행한 뒤 브라우저에서 http://localhost:3000을 열어 .ent 파일을 불러오세요.

막힐 때

PowerShell에서 "이 시스템에서 스크립트를 실행할 수 없으므로…"가 나와요

Windows의 실행 정책 때문입니다. 설정을 바꿀 필요 없이 npm 대신 npm.cmd, npx 대신 npx.cmd로 실행하면 됩니다. 위 프롬프트에 이미 들어 있어서 AI가 알아서 바꿉니다.

AI가 명령 실행이나 인터넷 접속을 허용할지 물어봐요

처음 설치할 때 npm, GitHub, 엔트리 사이트에서 파일을 내려받아야 해서 허용이 필요합니다. 허용하지 않으면 설치가 중간에 멈춥니다.

설치(setup)가 중간에 실패했어요

npm run setup은 여러 번 실행해도 안전합니다. 오류 메시지대로 조치한 뒤 다시 실행하게 하세요. 엔트리 엔진을 직접 빌드하려고 하면 멈추게 하세요 — 빌드는 필요 없습니다.

Chromium(검사용 브라우저) 설치가 안 돼요

작품 파일은 그래도 만들어집니다. 다만 실제로 실행해 보는 검사를 못 하므로, AI가 "런타임 검증 미수행 — 사유"를 보고에 적게 되어 있습니다. 이때는 npm start로 편집기를 열어 직접 실행해 보세요.

예전에 받아 둔 저장소 폴더가 있어요

새 기능과 수정이 반영되도록 먼저 git pull을 실행하세요.

링크를 줬는데 AI가 문서를 안 읽고 바로 만들어요
